Deep Agent keeps application infrastructure behind small, replaceable contracts. Choose one extension surface for each responsibility rather than making model prompts carry application secrets or runtime policy.

| Need | Start here |
| --- | --- |
| Long-lived agent facts and preferences | [Persistent memory](/deep-agent/persistent-memory) |
| Reusable, on-demand task instructions | [Skills](/deep-agent/skills-and-instructions) |
| Parallel or specialized delegated work | [Subagents and delegation](/deep-agent/subagents-and-delegation) |
| Tools and read-only resources from external systems | [MCP and OAuth](/deep-agent/mcp-and-oauth) |
| Deliberate JavaScript evaluation and narrow callable capabilities | [Interpreter tools](/deep-agent/interpreter-tools) |

`DeepHarnessProfile` selects the built-ins suitable for a particular model or deployment: workspace, todos, skills, memory, sandbox, interpreter, subagents, and MCP resources. Application-supplied `ChatTool`s remain available regardless of the profile. Use `DeepHarnessProfile.defaults()` to enable every built-in, or construct a profile with only the capabilities your deployment supports.
